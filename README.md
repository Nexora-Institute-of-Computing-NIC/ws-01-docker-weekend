# Docker in a Weekend

**Category:** Workshop - **Duration:** 2 sessions, ~4 hours total - **Sessions:** 2

> **Status:** Scaffolded. Content in progress.

## What you will learn

Containerise an application, write a Dockerfile, manage images, and run multi-service stacks with Docker Compose.

## Who this is for

Anyone who has written code and wants to understand how it gets into containers.

## Sessions

- [Session 1](sessions/session-01.md) - Getting started with containers
- [Session 2](sessions/session-02.md) - Composing multi-service applications
